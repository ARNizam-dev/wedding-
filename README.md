# Wedding Invitation (React + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist (upload to Netlify / Vercel / any host)

Edit **src/data/config.js** for names, dates, events, photos, map link, WhatsApp RSVP number, music.
Put images/music in **/public** and reference them like "/groom.jpg".
Flow: notebook intro → door → full invitation. RSVP opens WhatsApp with a prefilled message (no backend needed).
